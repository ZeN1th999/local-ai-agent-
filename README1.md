A local AI powered by Qwen 3.8 and Gemma 4, featuring 25 billion parameters. 
This AI can read text, analyze images, and create or edit files in all popular formats. 
It is capable of writing code, building presentation websites, and generating standard presentations.
Additionally, it comes with a custom user interface that supports various themes and custom backgrounds. 
The agent can also speak and listen via a microphone; if the wake-word feature is enabled, it will respond whenever its name is called. 
You can choose between two agents—one with a male voice and one with a female voice—both capable of maintaining a conversation consistent
with their distinct personalities (the personality prompts can be customized directly in the configuration files).
As for the technical details: I built and optimized this entire setup on my own low-end PC, 
which has a GTX 1650 and 16 GB of RAM—a rather modest specification for running AI.
If your hardware configuration is better, everything will run significantly faster.
All parameters can be tweaked in the config file.
One of the main advantages of this agent is its low resource consumption compared to others, 
allowing you to run it alongside other tasks (though on my specific setup, hardware utilization reaches nearly 100%, 
so performance depends entirely on your components). More detailed technical information can be found in the README file. Enjoy the experience!
